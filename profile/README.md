# MCU Definitions

Open-source libraries and resources for low-level hardware development.

The organization maintains hardware definition libraries, technical documentation, datasheets and supporting tools for microcontrollers, microprocessors and embedded systems.

## Repositories

### Hardware Definitions

Modular, header-only C++ definitions for specific microcontrollers and microprocessors.

| Repository | Description | Documentation |
| --- | --- | --- |
| [ATmega328P](https://github.com/mcu-definitions/atmega328p) | Hardware definitions for the ATmega328P. | [API docs](https://mcu-definitions.github.io/atmega328p/) |
| [ATmega2560](https://github.com/mcu-definitions/atmega2560) | Hardware definitions for the ATmega2560. | [API docs](https://mcu-definitions.github.io/atmega2560/) |

### Adapter Interfaces

Hardware-independent interfaces for MCU peripheral adapters.

| Repository | Description | Documentation |
| --- | --- | --- |
| [Adapter](https://github.com/mcu-definitions/adapter) | Standardized interfaces for common microcontroller peripherals. | [API docs](https://mcu-definitions.github.io/adapter/) |

### Resources

Technical resources supporting hardware development.

| Repository | Description |
| --- | --- |
| [Datasheets](https://github.com/mcu-definitions/datasheets) | Official datasheets for components and devices used in MCU Definitions projects. |

## Architecture

MCU Definitions separates hardware definitions, reusable adapter contracts, device-specific implementations, and peripheral libraries.
